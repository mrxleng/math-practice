# 20以内加减法

5 分钟语音练习。用 Chrome 打开 <https://mrxleng.github.io/math-practice/> ，点「开始练习」并允许麦克风，说出 0 到 20 的答案。说对计 1 题并换下一题，说错不换题、不加分。时间到后停止收音和计分，并显示答对多少题。手动输入只是备用。

在 Chrome 里，语音识别通常会把声音发给浏览器的在线识别服务，需要联网，不是只在这台设备上完成。本页不保存录音，也不请求摄像头。

入口是仓库根目录的 `index.html`，从 `main` 的 `/` 发布。说明见 [配置 GitHub Pages 发布来源](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)。
